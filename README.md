# NAKX FITS — AI Fitness & Nutrition Coach

NAKX FITS is a modern fitness and nutrition web application designed to provide users with a centralized platform for managing workouts, nutrition, fitness progress, and personalized coaching.

## 🚀 Features

* 🏋️ **Workout Tracking** — Log and manage workout sessions and exercise sets.
* 🍎 **Diet & Nutrition** — Track daily meals, calories, and nutritional information.
* 📊 **Progress Tracking** — Monitor weight trends, calorie intake, and training progress.
* 🤖 **AI Fitness Coach** — Interact with an AI-powered coach for fitness-related guidance.
* 💪 **Custom Workouts** — Create and manage personalized workout routines.
* 👤 **User Profile** — Store and update fitness-related profile information.
* 🔐 **Authentication** — User authentication and profile management through Supabase.
* 📱 **Responsive UI** — Modern interface designed for different screen sizes.

## ⚙️ Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```

### 4. Preview the production build

```bash
npm run preview
```

## 🎯 Project Goal

The goal of NAKX FITS is to combine workout tracking, nutrition management, progress monitoring, and AI-based coaching into a single fitness platform that makes maintaining a consistent fitness routine easier.
